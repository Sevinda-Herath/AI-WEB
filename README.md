# LSTM Sentiment Project - Website

## Overview

This repository contains the website component of an LSTM-based sentiment analysis project. This is a web interface designed to showcase sentiment analysis capabilities.

## About This Project

This website serves as a front-end interface for a sentiment analysis system. The project focuses on providing an accessible way to interact with and visualize sentiment analysis results.

## Getting Started

### Prerequisites

- Web browser
- Local web server (optional for local development)

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/Sevinda-Herath/LSTM-Sentiment-Project---Website.git
   ```
2. Open the index.html file in your web browser or set up a local server to host the website.

## Usage

Navigate through the website to learn about and interact with the sentiment analysis features provided.

## Project Structure

The repository follows a standard web project structure with HTML, CSS, and JavaScript files organized in a logical manner.
